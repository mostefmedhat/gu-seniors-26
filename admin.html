Live view of the orders spreadsheet.

⚠ This page is public — GitHub Pages has no login.

The only thing protecting buyers' phone numbers is the spreadsheet's own sharing setting. Keep the sheet shared with specific people only. Then this frame renders the data for whoever is signed in and shows a "request access" box to everyone else.

Never set the sheet to "Anyone with the link can view" — that would put every buyer's number on the open internet.
